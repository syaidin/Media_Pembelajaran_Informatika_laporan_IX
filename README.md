# MISSION: REPORT MASTER
## Website Pembelajaran Interaktif - Informatika SMP

### 📚 Tentang Project

**MISSION: REPORT MASTER** adalah website pembelajaran interaktif berbasis gamifikasi untuk mata pelajaran Informatika SMP dengan topik **LAPORAN**. Website ini dirancang sebagai media pembelajaran digital yang modern, interaktif, bermakna, dan menyenangkan untuk siswa SMP/Fase D.

### 🎯 Tujuan Pembelajaran

1. Peserta didik mampu memahami pengertian dan tujuan laporan
2. Peserta didik mampu mengidentifikasi ciri-ciri laporan yang baik
3. Peserta didik mampu memahami struktur laporan
4. Peserta didik mampu membedakan fakta, data, dan opini dalam laporan
5. Peserta didik mampu menganalisis informasi untuk digunakan dalam laporan
6. Peserta didik mampu menyusun laporan dengan struktur yang benar
7. Peserta didik mampu menyajikan informasi secara sistematis dan logis
8. Peserta didik mampu melakukan refleksi terhadap proses pembelajaran

---

## ✨ Fitur Utama

### 🎮 Gamifikasi Penuh
- **Progress Tracking**: Progress bar menampilkan persentase penyelesaian misi
- **Mission System**: 11 misi yang harus diselesaikan secara bertahap
- **Badge System**: 5 badge yang dapat diraih berdasarkan pencapaian
- **Locked/Unlocked**: Sistem kunci misi untuk pembelajaran terstruktur

### 📊 11 Misi Pembelajaran

#### **MISSION 01 - PRETEST** 🧠
- 10 soal pilihan ganda
- Mengukur pengetahuan awal siswa
- Feedback otomatis untuk setiap jawaban
- Pembahasan lengkap

#### **MISSION 02 - KENALI LAPORAN** 📚
- Materi lengkap tentang laporan
- Kartu interaktif yang dapat diklik
- 9 topik materi:
  - Pengertian Laporan
  - Tujuan Laporan
  - Fungsi Laporan
  - Ciri-ciri Laporan
  - Jenis-jenis Laporan
  - Bahasa dalam Laporan
  - Fakta, Data, dan Opini
  - Sumber Informasi
  - Etika Menggunakan Informasi

#### **MISSION 03 - STRUKTUR LAPORAN** 🧩
- Visualisasi 10 bagian struktur laporan
- Modal detail untuk setiap bagian struktur
- Contoh laporan sederhana yang lengkap

#### **MISSION 04 - REPORT BUILDER** 🛠️
- Simulasi membuat laporan dengan 10 tahap
- Kasus: Survei Penggunaan Internet Siswa
- Data yang disediakan
- Report Checker dengan 5 aspek penilaian:
  - Struktur (90%)
  - Kelengkapan (85%)
  - Analisis Data (88%)
  - Bahasa (80%)
  - Kesimpulan (92%)

#### **MISSION 05 - QUIZ EASY** 🟢
- 10 soal level mudah
- Fokus: mengingat, memahami, mengenali
- Badge "DATA EXPLORER" jika skor ≥80

#### **MISSION 06 - QUIZ MEDIUM** 🟡
- 10 soal level menengah
- Fokus: penerapan, klasifikasi, analisis kasus
- Badge "STRUCTURE MASTER" jika skor ≥80

#### **MISSION 07 - QUIZ EXPERT** 🔴
- 10 soal HOTS (Higher Order Thinking Skills)
- Fokus: analisis, evaluasi, interpretasi
- Badge "CRITICAL THINKER" jika skor ≥80

#### **MISSION 08 - REPORT CHALLENGE** 🏆
- Final Project: Membuat laporan lengkap
- 5 pilihan tema:
  - Kebiasaan Penggunaan Internet Siswa
  - Penggunaan Gadget di Lingkungan Sekolah
  - Pemanfaatan Teknologi untuk Belajar
  - Keamanan Digital Siswa
  - Penggunaan AI dalam Pembelajaran
- Checklist kelengkapan
- 11 bagian laporan yang harus diselesaikan

#### **MISSION 09 - POSTTEST** 🧠
- 15 soal pilihan ganda
- Mengukur perkembangan pemahaman
- Perbandingan dengan Pretest
- Kalkulasi Learning Gain

#### **MISSION 10 - REFLEKSI 4P** 💭
- **Peristiwa**: Pengalaman penting selama pembelajaran
- **Perasaan**: Skala emosi dengan emoji
- **Pembelajaran**: Pengetahuan/keterampilan baru
- **Penerapan**: Rencana penerapan di kehidupan nyata
- **Kesimpulan**: Kemampuan yang telah dikuasai

#### **MISSION 11 - HASIL BELAJAR** 🎓
- Tampilan semua skor
- Nilai akhir dengan formula:
  - Quiz Easy: 10%
  - Quiz Medium: 10%
  - Quiz Expert: 15%
  - Report Builder: 15%
  - Project: 20%
  - Posttest: 30%
- Status: Sangat Baik / Baik / Cukup / Perlu Bimbingan
- Learning Gain
- Kompetensi yang dicapai
- Badge yang diraih
- Export data (JSON)

### 🏅 Sistem Badge

1. **🏅 DATA EXPLORER** - Selesaikan Quiz Easy dengan skor ≥80
2. **🏅 STRUCTURE MASTER** - Selesaikan Quiz Medium dengan skor ≥80
3. **🏅 REPORT BUILDER** - Selesaikan Report Builder/Project
4. **🏅 CRITICAL THINKER** - Selesaikan Quiz Expert dengan skor ≥80
5. **🏆 REPORT MASTER** - Selesaikan semua 11 misi

### 👨‍🏫 Dashboard Guru

- Jumlah siswa
- Rata-rata Pretest & Posttest
- Learning Gain rata-rata
- Persentase ketuntasan
- Rata-rata quiz semua level
- Learning Insights
- Rekomendasi pembelajaran

## 🚀 Cara Menggunakan

### Untuk Siswa:

1. **Buka Website**
   - Buka file `index.html` di browser (Chrome/Firefox/Edge)
   - Akan muncul halaman cover "MISSION: REPORT MASTER"

2. **Mulai Misi**
   - Klik tombol "🚀 MULAI MISI"
   - Isi identitas: Nama, Kelas, Nomor Absen
   - Klik "LANJUTKAN"

3. **Dashboard**
   - Lihat semua misi yang tersedia
   - Misi 1 otomatis terbuka
   - Klik misi untuk memulai

4. **Selesaikan Misi Berurutan**
   - Mulai dari Mission 01 (Pretest)
   - Selesaikan hingga Mission 11 (Hasil Belajar)
   - Misi berikutnya akan terbuka setelah misi sebelumnya selesai

5. **Kumpulkan Badge**
   - Raih skor tinggi untuk mendapatkan badge
   - Lihat badge di dashboard

6. **Export Hasil**
   - Di Mission 11, klik "📥 EXPORT HASIL BELAJAR"
   - File JSON akan terunduh
   - Kirim file ke guru

### Untuk Guru:

1. **Akses Teacher Dashboard**
   - Buka file dan tambahkan `/teacher` di URL
   - Atau buat link khusus ke halaman guru

2. **Monitor Progress**
   - Lihat statistik kelas
   - Analisis learning gain
   - Identifikasi siswa yang perlu bimbingan

3. **Terima Data Siswa**
   - Siswa export data JSON
   - Kumpulkan semua file JSON
   - Analisis menggunakan spreadsheet atau tools lain

## 🔧 Kustomisasi

### Mengganti Identitas Sekolah

Edit file `index.html` bagian cover page:
```html
<span class="info-value">[NAMA SEKOLAH]</span>
<span class="info-value">[NKSN/NPSN]</span>
<span class="info-value">[NAMA GURU]</span>
```

Ganti dengan data sekolah Anda.

### Menambah/Mengubah Soal

Edit file `script.js`:
- `pretestQuestions` - Soal Pretest
- `quizEasyQuestions` - Soal Quiz Easy
- `quizMediumQuestions` - Soal Quiz Medium
- `quizExpertQuestions` - Soal Quiz Expert
- `posttestQuestions` - Soal Posttest

Format soal:
```javascript
{
    question: "Pertanyaan?",
    options: [
        "Opsi A",
        "Opsi B",
        "Opsi C",
        "Opsi D"
    ],
    correct: 0, // Index jawaban benar (0-3)
    explanation: "Pembahasan jawaban"
}
```

### Mengubah Warna Tema

Edit file `style.css` di bagian `:root`:
```css
:root {
    --primary-blue: #2563eb;
    --cyan: #06b6d4;
    --purple: #8b5cf6;
    /* ... */
}
```

## 🐛 Troubleshooting

### Data Hilang
**Masalah**: Data siswa hilang setelah refresh
**Solusi**: 
- Pastikan browser tidak dalam mode Incognito/Private
- Jangan clear browser cache
- Backup data dengan export JSON

### Misi Terkunci
**Masalah**: Tidak bisa membuka misi selanjutnya
**Solusi**:
- Pastikan misi sebelumnya sudah diselesaikan
- Klik tombol "LANJUT KE MISSION XX"
- Refresh halaman dan coba lagi

### Tombol Tidak Berfungsi
**Masalah**: Tombol tidak merespons klik
**Solusi**:
- Pastikan JavaScript aktif di browser
- Cek console browser (F12) untuk error
- Refresh halaman

### Layout Berantakan di Mobile
**Masalah**: Tampilan tidak rapi di smartphone
**Solusi**:
- Gunakan browser modern (Chrome/Firefox)
- Rotate ke landscape untuk konten lebih luas
- Zoom out jika perlu
