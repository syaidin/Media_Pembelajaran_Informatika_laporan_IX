# 🎓 MISSION: REPORT MASTER

## Website Pembelajaran Interaktif - Informatika SMP
### Tema: "Ubah Informasi Menjadi Laporan yang Bermakna"

---

## 📚 Deskripsi

Website pembelajaran interaktif gamifikasi untuk mata pelajaran Informatika SMP dengan tema pembuatan laporan. Siswa akan menjalani 11 misi pembelajaran yang dirancang secara progresif untuk memahami konsep, struktur, dan praktik pembuatan laporan formal.

---

## ✨ Fitur Utama

### 🎮 11 Misi Pembelajaran Interaktif
1. **Cover Page** - Halaman pembuka dengan animasi
2. **Identity Form** - Form identitas siswa
3. **Dashboard** - Pusat kontrol misi dengan progress tracking
4. **Mission 01: Pretest** - Uji pemahaman awal (10 soal)
5. **Mission 02: Kenali Laporan** - Materi pembelajaran (9 topik expandable)
6. **Mission 03: Struktur Laporan** - Penjelasan 8 bagian formal laporan
7. **Mission 04: Report Builder** - Pembuat laporan interaktif (10 langkah)
8. **Mission 05: Quiz Easy** - Level mudah (10 soal)
9. **Mission 06: Quiz Medium** - Level sedang (10 soal)
10. **Mission 07: Quiz Expert** - Level sulit (10 soal)
11. **Mission 08: Report Challenge** - Proyek laporan mandiri
12. **Mission 09: Posttest** - Uji pemahaman akhir (15 soal)
13. **Mission 10: Refleksi 4P** - Refleksi pembelajaran
14. **Mission 11: Hasil Belajar** - Sertifikat dan badge

### 🏅 Sistem Gamifikasi
- **5 Badge System:**
  - 🏅 DATA EXPLORER (Quiz Easy ≥80%)
  - 🏅 STRUCTURE MASTER (Quiz Medium ≥80%)
  - 🏅 REPORT BUILDER (Selesai Mission 4)
  - 🏅 CRITICAL THINKER (Quiz Expert ≥80%)
  - 🏆 REPORT MASTER (Selesai semua misi)

- **Progress Tracking:**
  - Progress bar global
  - Status setiap misi (Locked/In Progress/Completed)
  - Skor untuk setiap quiz dan aktivitas
  - Learning gain (Perbandingan Pretest vs Posttest)

### 📝 Mission 03: Struktur Laporan (Enhanced)
**Penjelasan lengkap 8 bagian formal laporan:**

1. **Halaman Judul**
   - Fungsi sebagai identitas laporan
   - Isi: Judul, Nama Penyusun, Kelas, Sekolah, Tahun
   - Contoh format profesional

2. **Kata Pengantar (Opsional)**
   - Struktur: Syukur, Tujuan, Terima kasih, Harapan
   - Contoh lengkap dengan indentasi
   - Tips penulisan

3. **Daftar Isi**
   - Fungsi navigasi laporan
   - Cara membuat dengan indentasi
   - Contoh format dengan nomor halaman

4. **BAB I - PENDAHULUAN**
   - A. Latar Belakang (Alasan kegiatan)
   - B. Rumusan Masalah (Pertanyaan fokus)
   - C. Tujuan (Hasil yang ingin dicapai)
   - D. Manfaat (Kegunaan untuk berbagai pihak)

5. **BAB II - PEMBAHASAN**
   - A. Dasar Teori (Konsep dan pengertian)
   - B. Alat dan Bahan (Jika ada)
   - C. Langkah-langkah Kegiatan/Metode
   - D. Hasil Kegiatan (Data yang diperoleh)
   - E. Pembahasan (Analisis hasil)

6. **BAB III - PENUTUP**
   - A. Kesimpulan (Ringkasan hasil)
   - B. Saran (Rekomendasi perbaikan)

7. **Daftar Pustaka**
   - Format Buku, Website, Data Primer
   - Contoh penulisan lengkap
   - Tips urutan alfabetis

8. **Lampiran (Jika Ada)**
   - Jenis: Foto, Screenshot, Kuesioner, dll
   - Cara penulisan dengan nomor urut
   - Contoh format

**Setiap bagian dilengkapi:**
- ✅ Penjelasan fungsi
- ✅ Cara membuat
- ✅ Contoh praktis
- ✅ Tips penulisan
- ✅ Visual styling (border, highlight, background)

## 🚀 Cara Penggunaan

### Untuk Siswa:

1. **Buka Website**
   ```

   ```

2. **Mulai Pembelajaran**
   - Klik "MULAI MISI" di cover page
   - Isi identitas (Nama, Kelas, Nomor Absen)

3. **Jalani Misi Berurutan**
   - Mission 01: Pretest (ukur pemahaman awal)
   - Mission 02: Pelajari materi laporan
   - Mission 03: Pahami struktur laporan (klik setiap bagian untuk detail)
   - Mission 04: Buat laporan formal
   - Mission 05-07: Uji pemahaman (3 level)
   - Mission 08: Project mandiri
   - Mission 09: Posttest
   - Mission 10: Refleksi
   - Mission 11: Lihat hasil & badge

4. **Tips Belajar**
   - Kerjakan misi secara berurutan (tidak bisa skip)
   - Baca feedback setelah quiz untuk belajar
   - Target minimal 80% untuk unlock badge
   - Manfaatkan fitur preview di Report Builder

### Untuk Guru:

1. **Akses Teacher Dashboard**
   - Klik menu "Teacher Dashboard" di navigation

2. **Monitoring**
   - Lihat statistik kelas (rata-rata, completion rate)
   - View individual student progress
   - Export data untuk analisis

3. **Kustomisasi (Opsional)**
   - Edit identitas sekolah di `index.html` (line ~50-70)
   - Edit soal quiz di `script.js` (search: `Questions`)
   - Edit materi di `index.html` (Mission 2)

## 📖 Panduan Troubleshooting

### Q: Quiz button tidak berfungsi?
**A:** Sudah diperbaiki di v1.1.0. Clear cache (Ctrl+F5) dan reload.

### Q: Data hilang setelah close browser?
**A:** Data tersimpan di localStorage. Jangan clear browser data/cookies.

### Q: Mission 3 masih menampilkan 10 cards?
**A:** Clear cache dengan Ctrl+Shift+Delete, hapus "Cached images and files", reload.

### Q: Gambar upload tidak muncul?
**A:** Maksimal ukuran 5MB. Format: JPG, PNG, GIF, WebP.

### Q: PDF download tidak bekerja?
**A:** Gunakan fitur Print to PDF browser (Ctrl+P → Save as PDF).

### Q: Tidak bisa skip mission?
**A:** By design. Harus selesaikan mission sebelumnya untuk unlock next mission.
